# 📌 Problem Statement

Women’s safety continues to be a significant global concern. In critical situations, victims often have less than 30 seconds to respond, yet most existing safety solutions depend on:

Manual SOS activation
Continuous internet connectivity
Inaccurate indoor positioning systems

These limitations make current systems ineffective when the user is unconscious, immobilized, or unable to react, thereby increasing vulnerability during emergencies.

# 💡 Proposed Solution

This project introduces an intelligent, solar-powered smartwatch that leverages multimodal sensor integration and Edge AI to autonomously detect unsafe situations. The system is capable of triggering emergency alerts within seconds, even in offline environments, ensuring continuous protection.

# ⚙️ Key Features
1. Multimodal Threat Detection
Real-time heart rate anomaly detection
Motion and impact analysis using accelerometer data
Audio-based threat recognition using offline inference
2. Autonomous SOS Activation
Automatic emergency alert generation within approximately 3 seconds
Eliminates the need for manual user interaction
3. Accurate Indoor Localization
Hybrid positioning using GPS and Wi-Fi fingerprinting
Trilateration and sensor fusion techniques
Enables floor-level and room-level accuracy indoors
4. Secure Emergency Communication
Real-time location sharing and live tracking
Transmission of 10-second audio evidence
Alerts sent to multiple pre-configured emergency contacts
5. Offline-First & Privacy-Centric Design
On-device Edge AI processing
Minimal reliance on cloud infrastructure
Enhanced data privacy and reduced latency
6. Solar-Assisted Charging
Supports extended device operation
Reduces dependency on frequent manual charging

# 🧠 System Architecture

The system is structured into three primary layers:

1. Data Acquisition Layer
Heart rate sensor
Accelerometer and motion sensors
Barometric sensor
Microphone
GPS and Wi-Fi modules
2. Edge AI Processing Layer
Detection of anomalies in physiological signals
Motion pattern classification
Audio context analysis
Threat probability scoring
3. Emergency Response Layer
Automatic SOS activation
Real-time location estimation
Secure and encrypted alert transmission

# Conclusion

This project demonstrates the potential of combining IoT and Edge AI to create an intelligent, reliable, and autonomous safety solution for women. Unlike conventional systems that depend on manual activation and continuous internet connectivity, the proposed smartwatch is capable of detecting threats in real time and initiating emergency responses automatically. By integrating multimodal sensor data—including physiological signals, motion patterns, and audio cues—the system ensures faster and more accurate identification of dangerous situations.

The implementation of offline processing enhances both privacy and reliability, making the system effective even in low-connectivity environments. Furthermore, features such as precise indoor localization and secure alert transmission significantly improve the overall responsiveness during emergencies.

In conclusion, this project highlights how advanced technologies can be leveraged to enhance personal safety and provide proactive protection, ultimately contributing towards a safer and more secure environment for women.
